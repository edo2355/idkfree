# IDKMEDIA Desktop (Windows / Mac / Linux)

Esta carpeta contiene la app de escritorio construida con Electron.

## Cómo ejecutar localmente:
1. `npm install`
2. `npm start`

## Cómo compilar el instalador:
- Para Windows: `npm run build:win`
- Para Mac: `npm run build:mac`
- Para Linux: `npm run build:linux`
